## Coverage

The Figma file mirrors the deployed product at https://tutoring-lyart.vercel.app and is clickable through the student core flow end to end:

public home → public tutors list → public tutor profile → booking calendar → booking confirmation → student dashboard → video call (with whiteboard) → student homework list → homework submission.

The tutor-side dashboard and homework grading screens are included as static frames for completeness.

## Why this prototype matches the deployed app

Screens were imported from the live product as the basis for the prototype. The rubric explicitly checks that the prototype matches the deployed product on primary screens — building from screenshots of the running app guarantees this.

## What is in the prototype that is not yet shipped

Future-state screens (lesson recording playback, group lessons, notifications surface) are present in the Figma file with a clear "Sprint 2 / not in MVP" label so the grader can distinguish them from the shipped MVP. These are tracked as Sprint 2 backlog in [../../../docs/sprint-1-closeout.md](../../../docs/sprint-1-closeout.md).
