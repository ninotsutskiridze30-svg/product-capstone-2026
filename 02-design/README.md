## Summary

- High-fidelity prototype published to Figma; covers the full student core flow end to end and matches the deployed product.
- **3 informal walkthrough sessions** completed with waitlist signups (2 students + 1 tutor) — per-participant observations recorded with the waitlist-signup initials. Additional sessions planned post-submission as more waitlist signups become available for short calls.
- One design change shipped in response to the strongest concrete finding (booking confirmation underweight); documented in [design-changes.md](user-testing/design-changes.md).
- Honest scope: these were short informal sessions, not full 20-minute moderated tests against the protocol in [usability-test-script.md](user-testing/usability-test-script.md). The protocol is the intended standard for the next round of testing.
