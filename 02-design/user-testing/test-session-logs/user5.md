# User Testing Session 5

## Participant

Third-year university student looking for programming tutors.

## Tasks Completed

* Browsed programming tutors
* Compared tutor descriptions
* Attempted tutor contact flow

## Observations

The participant preferred detailed tutor profiles and spent more time viewing tutors with clearer descriptions.

## Feedback

“This is faster than searching randomly through Facebook posts.”

## Suggested Improvements

The participant suggested adding tutor ratings and reviews in future versions.
