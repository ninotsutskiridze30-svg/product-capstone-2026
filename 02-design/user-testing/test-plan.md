# User Testing Plan

## Goal

Evaluate whether university students can quickly and confidently discover tutors using the TutorLink MVP.

## Participants

The testing sessions included university students from KIU and other local universities.

## Tasks

Participants were asked to:

1. Open the platform
2. Browse available tutors
3. Open a tutor profile
4. Attempt to contact or select a tutor
5. Switch platform language

## Metrics Observed

* Ease of navigation
* Time required to find tutors
* Trust in tutor profiles
* Overall usability
* User confusion points

## Testing Method

Moderated usability testing sessions conducted through direct observation and short feedback interviews.
