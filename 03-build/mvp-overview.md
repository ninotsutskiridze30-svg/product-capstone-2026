# MVP Overview

## Product

TutorLink is a tutoring discovery platform designed to help university students quickly find reliable tutors.

## Current MVP Capabilities

- Tutor browsing
- Tutor profile viewing
- Responsive interface
- Multilanguage support
- Simple discovery flow

## Deployment

Live MVP:
https://tutoring-lyart.vercel.app/en

## Goal

The MVP focuses on validating whether students prefer a structured tutoring platform over informal discovery methods such as Facebook groups and Telegram chats.
